# Power Electronics Learning

Educational material for learning and analyzing power electronics using:

* Python
* Jupyter Notebooks
* Google Colab
* ngspice

The repository is organized into four learning blocks.

## Block 1 — Power Electronics Fundamentals

Fundamental concepts required for the analysis of power electronic circuits.

### Topic 1 — RMS Value and Average Power

* Average value of periodic signals
* RMS value
* Instantaneous power
* Average power
* Sinusoidal signals
* Bipolar square waves
* Unipolar square waves
* Triangular waveforms
* Multi-level signals
* Comparison between theoretical results, Python and ngspice

## Block 2 — DC-DC Converters

Analysis and simulation of fundamental DC-DC converters.

* Buck converter
* Boost converter
* Buck-Boost converter
* Cuck converter

## Block 3 — AC-DC converters

* Analysis of power conversion circuits and switching waveforms.
* Controlled Rectifier circuits 
* Non controlled rectifiers circuits

## Block 4 — isolated DC-DC converters
* Flyback converter
Integration of Python and ngspice for the analysis and design of power electronic systems.
